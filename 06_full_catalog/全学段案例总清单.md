## 五、明确不做（11 个）

| ID | 案例 | 原因 |
|---|---|---|
| PH-J15 | 大气压与海拔 | 只有单调趋势，没有可复算的数值关系，审查只能验有没有 |
| PH-H08 | 带电粒子在磁场中的运动 | 三维空间轨迹难以用二维 canvas 忠实表达，且中学阶段不做定量 |
| CH-P02 | 物理变化与化学变化 | 纯分类判断，无参数可调，交互退化为选择题 |
| CH-J06 | 金属活动性顺序 | 金属活动性顺序是记忆性规则，无可调自变量 |
| CH-H07 | 原电池原理 | 原电池以电子流向判断为主，无定量模型 |
| CH-H09 | 晶体结构与配位数 | 晶胞三维结构在单页二维里难以准确呈现 |
| BI-P02 | 食物链与食物网 | 食物网是关系图，无标量可验 |
| BI-J07 | 心脏结构与血液循环 | 纯结构标注，审查只能验齐全，验不了对错 |
| GE-P02 | 气温与天气统计 | 读图题，交互空间小，本质是静态图表 |
| GE-H02 | 热力环流 | 定性环流，无可复算数值 |
| CS-P02 | 循环画正多边形 | 依赖编程环境执行结果，静态页无法自证 |

**这不是能力不足，是边界选择**：自动化质量审查在无模型内容上失效，硬做只会产出「满分但没用」的页面。

## 六、字段与接入

| 字段 | 用途 | 下游谁消费 |
|---|---|---|
| 可调参数 | 决定页面滑块 | 03 生成 Agent、04 审查（控件数量检查） |
| 核心模型 | 决定公式与审查判据 | 03 生成提示词、04 公式自洽校验 |
| 审查判据 | 该项「算不算对」的判定方式 | 04 审查 Agent |
| 建议文件名 | 交付物命名 | `runs/` 归档 |
| 输入句 | 流水线的一句话需求 | `run_pipeline.py` |

新增一个学科的固定动作：

1. `topics.py` 加一条 profile（关键词、检索侧重、单位组、数值上限、公式示例）
2. `02_retrieval_agent/knowledge/` 放 5 个带 `主题:` 字段的 md
3. `04_review_agent/checks_browser.js` 加一套公式判据 —— **当前唯一需要写代码的地方**

> 第 3 步建议一次性改成通用赋值式求值器（抓 `左 = 表达式 = 结果`，求值后比对），
> 之后新增学科零代码。否则每加一个学科就要多写一套正则，是线性增长。
