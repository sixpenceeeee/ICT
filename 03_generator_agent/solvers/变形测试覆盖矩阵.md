# 数理化求解器变形测试覆盖矩阵

本矩阵区分两类测试：

- **求解器层**：直接变换结构化输入，断言计算结果必须满足的数学/学科关系。
- **页面层**：质量审查在浏览器里改变真实页面控件，抓取更新后的请求和结果，再由 Python 独立参考实现复算。方程配平页还会在浏览器中变换化学式表示，并测试学生系数整体倍乘。

## 数学

| 求解器 | 求解器层变形关系 | 页面层变形与复核 |
|---|---|---|
| 正方体、长方体、三棱柱、正四棱锥截面 | 平面方程的法向量和偏移量同倍缩放或同时反号，截面边数、面积、顶点不变 | 改页面截面参数；检查请求/几何参数和结果更新，Python 几何内核复算每个状态 |
| 圆柱、圆锥、球截面 | 平面法向量和偏移量同倍缩放或反号，截面形状和面积不变 | 改页面截面参数；Python 截面参考实现复算页面结果与绘图签名 |
| 空间距离与角度 | 坐标整体放大 k 倍，距离放大 k 倍、角度不变；方向向量或平面方程同倍缩放，几何量不变 | 改页面输入；检查请求和结果更新，并与 Python 向量求解器对拍 |
| 立体体积、组合体体积、分割守恒 | 所有长度放大 k 倍，体积放大 k³；组合求和及分割相对误差保持一致 | 改页面尺寸或组成参数；每个状态由 Python 体积实现复算 |
| 正方体、长方体、圆柱、圆锥展开折叠 | 等比例放大尺寸后拓扑/有效性不变，长度放大 k 倍、面积放大 k² | 改页面尺寸/展开参数；Python 独立复算尺寸约束、面积守恒和折叠坐标 |

空间距离/角度及多面体不同立体适配器的补充变形用例集中在 `tests/test_metamorphic_solver_coverage.py`；各展开图、曲面截面、体积和配平原有测试仍保留在各自 `tests` 目录。

### 数学教学题型

题型契约、控件预设和变形关系集中在 [lesson_models.json](mathematics/lesson_models.json)。G4-32 通过浏览器的真实控件到达各个预设，再验证关系。J3-30 至 J3-54 用 Python 独立复算每个页面请求并核对可见读数。离线固定页验收位于 `04_review_agent/tests/test_lesson_solvers.py`。

| 求解器 | 页面变形与复核 |
|---|---|

| 直角三角形 | 双边同比缩放，斜边同比、面积平方缩放、角度不变。交换直角边对换正余弦 |

| 等差与等比数列 | 首项、公差同比缩放。覆盖公比 1、正负交替、单项 |
| 反比例函数 | 改变取样横坐标，乘积保持。比例系数反号切换象限 |
| 三角函数图像 | 缩放正弦波振幅和频率，检查取样值与周期。相位可表达余弦 |
| 指数与对数函数 | 底数取倒数时对数反号。复核指数值、互逆关系和增减性 |
| 函数图像变换 | 平移、反射平方函数与绝对值函数，核对新顶点和取样值 |
| 导数与切线 | 二次多项式上下平移保持斜率。覆盖水平切线和一次函数 |
| 相似三角形 | 相似比线性改变周长、平方改变面积。换序保持面积 |
| 圆的度量、弦与圆周角 | 半径与弦距同比放大，弦和周长线性、面积平方放大，角度不变 |
| 多边形面积与割补 | 上下底交换面积不变。覆盖梯形、三角形、平行四边形与等积矩形 |
| 尺规作图 | 线段缩放时中点同比移动。锐角、直角、钝角分别平分 |
| 椭圆与离心率 | 半轴同比缩放保持离心率。圆形特例的两焦点重合 |
| 有限抽样与树状图概率 | 切换放回方式，复核完整命中次数分布、零概率事件和放回时同比增加球数 |
| 二项分布 | 互换成功和失败，概率和方差按对称关系保持。覆盖 p=0 和 p=1 |
| 一元线性回归 | 三对观测值换序不变。平移纵坐标和缩放横坐标时复核斜率 |
| 平面向量数量积 | 交换向量保持点积和夹角。覆盖同比缩放、垂直与零向量 |
| 分数加减 | 等值分数替换保持约分结果。覆盖减法负值和零结果 |
| 基本不等式 | 交换输入保持均值差。覆盖同比缩放、两数相等、含零 |
| 三视图投影 | 台阶体等比缩放，投影面积平方缩放、体积立方缩放。覆盖无台阶和等宽台阶 |
| 球与长方体的切接 | 边长换序或同比缩放时复核内外球半径。核对最短边重复时的切面数 |
| 立体表面最短路径 | 长方体对顶点换轴和同比缩放时复核三种展开路线及最短值 |
| 祖暅原理与等积变换 | 水平剪切保持矩形水平截面积和体积。等比缩放复核平方和立方关系 |
| 行程问题 | 改变间距、相对速度，核对相向相遇、同向追及、同速不相遇和同起点 |

## 物理

| 求解器 | 求解器层变形关系 | 页面层变形与复核 |
|---|---|---|
| 直流电路 MNA 求解器 | 固定电阻时电源电压放大 k 倍，节点电压/支路电压/电流放大 k 倍、功率放大 k²；固定电压时电阻放大 k 倍，支路电压不变、电流和功率缩小为 1/k | 浏览器改变电路页滑块、数值框或选择器，要求网表/结果随之更新；Python 独立 MNA 对拍每个变形状态，并检查电表绑定和电路拓扑签名 |
| 浮力与浮沉 | 排液体积加倍则浮力加倍。物体密度跨过液体密度时，自由状态依次为上浮后漂浮、悬浮、下沉 | 操作浸没比、体积、密度和模式控件。J3-16 复算排液体积、浮力、重力、测力计示数及状态 |
| 杠杆平衡 | 同侧力加倍且力臂减半时力矩不变。交换两侧后净力矩反号 | 操作四个力及力臂控件，覆盖平衡和两侧下沉。J3-17 复算力矩与方向 |
| 液体压强 | 深度加倍则表压加倍。密度加倍、深度减半时表压不变，液面表压为零 | 操作密度和深度控件。J3-18 复算表压 |
| 比热容 | 同热量下质量或比热容加倍，温升减半。质量与热量同倍变化时温升不变 | 操作质量、比热容、初温和热量控件，覆盖吸热、放热和零热量。J3-19 复算温差与末温 |
| 匀变速直线运动 | 从静止出发时间加倍，速度加倍、位移变为四倍。反向时检验路程与位移的差别 | 操作初速度、加速度和时间控件。J3-20 复算速度、位移、路程和轨迹采样 |
| 平抛运动 | 水平初速度加倍，水平位置和水平速度加倍，竖直位置、竖直速度及飞行时间不变。高度变为四倍时飞行时间加倍 | 操作初速度、高度和时间控件，覆盖竖直下落和触地。J3-21 复算两方向分量、落点和轨迹采样 |
| 折射与全反射 | 交换介质并沿折射光线反向入射，光路可逆。跨过临界角时依次出现折射、临界折射和全反射 | 操作两侧折射率和入射角控件。J3-22 复算反射角、折射角、临界角及状态 |
| 一维受力与摩擦 | 水平外力跨过最大静摩擦力时从静止转为滑动。同一外力在静止和已滑动时分别产生静摩擦与动摩擦。滑动速度反号时摩擦力反号。无外力滑动时质量加倍，摩擦力加倍、加速度不变 | 操作质量、外力、当前速度和两种摩擦系数。J3-23 从动量平衡反推接触冲量，复算摩擦力、合力、加速度及受力状态，并核对重力和支持力 |
| 功与功率 | 固定力和位移，仅改变夹角，覆盖正功、零功和负功。耗时加倍，功不变、平均功率减半。位移与耗时同比增加时平均功率不变 | 操作力、位移、夹角和耗时。J3-24 从功率—时间图的有符号面积独立复算功，核对结果及页面读数。故意把垂直作用的结果替换为顺向做功，确认审查拦截 |
| 机械能变化与守恒 | 初、末高度同量平移时末速度不变。非保守力做负功时机械能减少。跨过末速度为零的临界点时报告能量缺口 | 操作质量、初速、两处高度和非保守力总功。J3-25 从净功和动能定理独立复算。故意把耗散状态替换为机械能守恒的结果，确认审查拦截 |
| 斜面 | 同高度的光滑斜面加长后省力但输入功不变。同高度的粗糙斜面加长时，摩擦耗能随水平底边增加，输入功可能在拉力减小时增加 | 操作质量、斜长、竖直高度和动摩擦系数。J3-26 先核算有用功与摩擦耗能，再由总功反推拉力。故意把粗糙斜面加长后的总功填成加长前的值，确认审查拦截 |
| 滑轮组 | 增加定滑轮时承重段数、拉力和绳端行程保持。相同滑轮总数可有不同承重段数。承重段加倍时理想拉力减半、绳端行程加倍 | 操作绳路、载荷、移动组件质量、提升高度和绳端阻力。J3-27 从绳路长度变化复算绳端行程，再用功反推拉力。故意把定滑轮个数当作承重段数，确认审查拦截 |
| 平面镜成像 | 物距加倍时像距加倍、像高保持。改变镜长或观察位置时像保持原位、可见区间变化。两个端点光线均错过镜面时，中间仍可能可见 | 操作物距、物高、观察位置和镜面半高。J3-28 按反射定律追迹并复算虚像与可见光路。把中段可见误报为不可见，确认审查拦截 |
| 波的传播与声速 | 固定介质测量结果时频率加倍，周期和波长减半，声速、到达时间和波前位置保持。换成更快的介质时频率保持，波长增大。覆盖波前到达前、刚到达和到达后 | 操作频率、探测距离、实测耗时和观察时间。J3-29 从波峰发射时刻和传播轨迹复算波长与位置。故意让频率加倍时波前提早到达，确认审查拦截 |

新增物理题型由 `physics/lesson_models.json` 为 G4-32 提供精确的控件输入和变形关系。学科审查对浏览器实际到达的每个状态分别复算，并核对可见读数。

## 化学

| 求解器 | 求解器层变形关系 | 页面层变形与复核 |
|---|---|---|
| 化学方程式配平与系数核验 | 化学式全体原子数同比缩放、ASCII/Unicode 下标转换、物质顺序重排时，最简系数和守恒关系按对应规律保持；学生系数整体乘整数后仍配平但不再最简 | 浏览器对页面内配平器执行化学式/顺序变形；配平教学页还会把学生系数整体乘 2，检查控件、校验状态和可见反馈，并由 Python 复算 |
| 反应计量/限量试剂 | 所有初始物质的量同比缩放，反应进度和限量试剂不变，反应程度、消耗量、剩余量和生成量同比缩放；进度从 0→0.5→1 时反应程度线性变化；化学计量比临界点下方/等于/上方分别识别限量试剂 | 浏览器用实际数量/进度控件改变输入，完成全体同比缩放和限量试剂临界点三态；Python 独立复算每个页面样本，并对拍缩放关系、守恒和限量试剂切换 |
| 溶液混合定量 | 等价 mL/L 输入结果不变；所有溶液体积同比缩放时初始物质的量和产物量同比缩放 | 浏览器实际改变浓度、体积、单位、进度；要求控件和请求同步，Python 独立复算并验证单位等价关系 |
| 强一元酸—强一元碱滴定 | 酸液和滴定液体积同时同比缩放时 pH、状态不变而物质的量同比缩放；mL/L 等价输入保持化学量不变；跨过当量点时状态按酸性→当量→碱性变化且 pH 递增 | 浏览器实际改变酸/碱浓度、体积和单位控件；页面审查要求 mL/L 等价样本及当量点前/当量点/当量点后三态，Python 逐状态复算请求、结果、方程和 pH |
| 气体制取与收集 | 反应物同比缩放时限量试剂不变、产气量与体积同比缩放；进度线性改变产气量；固定气体量时 V/T 与干气分压成反比；改变总压时 P干气·V 不变；排水集气满足 P总=P干气+P水蒸气，且同条件体积大于干燥集气 | 浏览器改变物质的量、反应进度、温度、压强和干燥/排水方式；质量审查由 Python 独立重算每个实际控件状态，并核对可见方程式、体积和画布状态 |
| 沉淀反应定量 | 两种溶液体积同比缩放时限量试剂不变、沉淀量同比变化；mL/L 等价输入结果不变；反应进度线性改变沉淀量；越过化学计量比临界点时限量试剂翻转 | 浏览器改变两份溶液的真实浓度/体积/单位和进度控件；自动构造临界配比及两侧状态；Python 独立复算每个状态、净离子方程式和显示质量 |
| 氧化还原离子方程式 | 改变酸/碱介质时，求解器只能补入对应的 H⁺ 或 OH⁻，且每种介质下都须分别满足原子、电荷和电子守恒；反应物、生成物各自换序时，对应系数按相同顺序换位，电子转移数与守恒总量不变 | 浏览器改变介质控件并点击真实物种换序按钮，采集变形后的结构化请求、结果、方程式、电子数和氧化数变化，由 Python 独立实现对拍；没有真实换序样本即 J3-12 fail |

酸碱滴定首版仅支持 25°C 理想模型下的强一元酸（HCl/HBr/HI/HNO3/HClO4）和强一元碱（LiOH/NaOH/KOH）；弱酸弱碱、多元酸碱、活度系数与指示剂终点误差尚未覆盖。

气体制取首版只计算用户明确给出的反应和目标气体，假定理想气体、完全按指定反应进度反应；排水集气使用 Antoine 水蒸气压近似，限 0–100°C。它不预测产物/收率，也不模拟气体溶解、泄漏和非理想气体效应。完整生成约束、Python 对拍与页面变形审查对应 `chemistry-gas-collection`、`hard_validate` 和 `J3-10`；独立求解器测试在 `chemistry/reactions/tests/test_gas_collection_solver.py`，真实浏览器验收脚本为 `chemistry/reactions/tests/browser_acceptance_gas_collection.js`。

沉淀反应首版采用六个明确反应模板（AgCl、BaSO₄、CaCO₃、Cu(OH)₂、Fe(OH)₃、Mg(OH)₂）。目录外组合明确报错，不推断为“不反应”；完全沉淀模型不计算 Ksp、残余溶解度、络合或副反应。页面审查项为 `J3-11`，真实控件变形要求共同放大、单位等价、浓度/进度变化和临界配比三态；独立求解器与管线测试位于 `chemistry/reactions/tests/test_precipitation_*.py`，真实浏览器脚本为 `chemistry/reactions/tests/browser_acceptance_precipitation.js`。

氧化还原配平首版要求输入明确的离子电荷、反应物/生成物和酸/碱介质；求解器以精确原子/电荷配平为底，再以氧化数变化独立核算电子得失。页面层用真实物种换序操作作为变形，质量审查项为 `J3-12`。不预测生成物或反应自发性；平均混合价态和氧化数无法确定的物种会拒绝处理。对应测试在 `chemistry/reactions/tests/test_redox_*.py`，浏览器脚本为 `chemistry/reactions/tests/browser_acceptance_redox.js`。

溶解平衡与 Ksp 首版要求显式提供固体化学式、Ksp、溶解离子的化学式/电荷/化学计量系数和初始浓度；求解器先检查原子和电荷组成，再在对数空间求解共同离子背景下的溶解度。页面变形真实操作 Ksp、共同离子浓度，并将 Q/Ksp 推到 1 的下方、等于和上方；J3-13 用 Python 独立实现对拍页面请求、读数、状态和溶解度。过饱和时不计算沉淀终态或产率。对应测试在 `chemistry/reactions/tests/test_solubility_equilibrium_*.py`，浏览器验收脚本为 `chemistry/reactions/tests/browser_acceptance_solubility_ksp.js`。

## 执行方式

求解器层总变形测试：

```powershell
python -m unittest discover -s 03_generator_agent/solvers -p "test_*.py" -v
```

配平器浏览器验收（需 Playwright 和浏览器）：

```powershell
cd 03_generator_agent/solvers/chemistry/equations
node tests/browser_acceptance.js
```

生成页面层测试由质量审查流程自动执行，报告项为 `G4-32 求解器页面变形测试`；适用的数学/物理/化学页面还会继续经过其学科独立复算项。页面没有把输入变化传入求解器、变形状态不符合独立计算或没有对应控件时，不通过页面层检查。
