## 可调参数
钩码重 G（1~10 N）、绕绳段数 n（2/3/4）、动滑轮重 G动（0.5~3 N）、摩擦设置（开/关）、上升高度 h（0.1~1 m）、效率条显示开关

## 可复算量
- η = Gh/(Fs) 与页面效率条一致（容差 1%）。
- 绳端距离 s 与 nh 一致（容差 1%）。
- 不计绳重摩擦时 F 与 (G + G动)/n 一致（容差 2%）。
- 每次显示的 η 满足 0 < η < 1（等价于 W有 < W总）。
- G 不变时增大 G动，η 单调减小；G动 不变时增大 G，η 单调升高。
- 开启摩擦后 F 增大、η 降低（变化方向校验）。

## 常见错误
- 在静止状态读拉力，额外功少算、η 偏高。
- 把 s 直接当 h 用，算出 η > 1。
- 认为同一滑轮组提升同一重物时，h 越大 η 越大（η 与 h 无关）。
- 认为绕绳段数越多效率越高。
- 忘记先测钩码重 G 就开始拉。
