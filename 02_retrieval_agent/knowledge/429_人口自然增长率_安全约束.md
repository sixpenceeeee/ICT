## 数值边界
- 出生率、死亡率 0~50‰，自然增长率由公式得出、可为负（下限 -20‰，越界提示）。
- 总人口 0.01 亿~15 亿（示意范围），年自然增长人口 = 总人口 × 自然增长率 ÷ 1000。
- 数据表年份必须连续，柱状图不得缺年。
- 总人口为 0 或负数时禁止计算并提示。

## 禁止生成
- 把公式写成「自然增长率 = 出生率 + 死亡率」。
- 声称自然增长率下降就是人口减少（只要大于 0 总人口仍在增加）。
- 把迁移造成的机械增长计入自然增长率。
- 出生率与死亡率单位一用 ‰ 一用 %，或直接混算。
