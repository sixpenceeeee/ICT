## 可调参数
质量 m(0.1~5 kg)、半径 r(0.1~10 m)、角速度 ω(0.5~50 rad/s)或周期 T 切换、向心力矢量显示开关、离心现象演示开关

## 可复算量
- v = ωr 是否与页面显示一致(容差 1%)。
- a = ω²r 与 a = v²/r 两种算法结果是否一致,并与页面加速度一致(容差 1%)。
- F = mω²r 是否与页面/标尺示数一致(容差 1%)。
- ω 与转速换算 n = ω/(2π) 是否一致(容差 1%)。
- 控制变量组:m、r 不变时 ω 加倍,F 是否变为 4 倍;m、ω 不变时 r 加倍,F 是否加倍(容差 2%)。

## 常见错误
- 认为匀速圆周运动是平衡状态、合力为零(合力即向心力,不为零)。
- 认为向心力消失后物体沿半径飞出(应沿切线)。
- 把向心力当成独立的一类力叠加在受力分析上,造成重复计算。
- 用 F = mv²/r 时把直径当半径,或 ω 与转速 n 混用不换算。
- 认为物体速度越大越「离心」而不分析合力是否足够提供向心力。
