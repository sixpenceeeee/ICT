## 器材与步骤
- 器材（教材实验「测量玻璃的折射率」口径）：平行玻璃砖、大头针、白纸、量角器、毫米刻度尺（或虚拟：激光笔、透明水槽、量角器）。
- 步骤一（折射光路）：画界面与法线，画出入射光线，标出入射角 θ₁ 与折射角 θ₂（都从法线量起）。
- 步骤二（测折射率）：改变入射角 3 次以上记录 θ₁、θ₂，由 n = sinθ₁/sinθ₂ 求各次折射率并取平均。
- 步骤三（临界角）：让光从光密介质（玻璃/水）射向空气，连续增大入射角，观察折射角趋近 90°，记录刚发生全反射时的临界角 C。
- 步骤四（光纤/水柱）：演示光沿弯曲水柱或光纤传播，解释为界面上的连续全反射。

## 操作要点
- 入射角、折射角必须从法线量起，n = sinθ₁/sinθ₂ 的分子必须是空气（真空）侧角的正弦。
- 插针法要点：两列针（P₁P₂ 与 P₃P₄）间距适当大、玻璃砖宽度与针距匹配，针距过近角度测量误差显著放大。
- 临界角演示要连续变化入射角并对比三种状态：一般折射（折射光弱）、掠射（折射角 90°）、全反射（只剩反射光）。
- 页面必须同时标注全反射的两个条件；翻转界面（空气→玻璃）时自动切换回折射状态。
- 折射率随介质不同而不同（水 1.33、玻璃约 1.5、金刚石 2.42），切换介质时同步切换折射率与临界角数值。
