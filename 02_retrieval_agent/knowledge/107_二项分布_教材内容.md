## 核心概念
- 伯努利试验:结果只有成功/失败两种、成功概率为 p 的试验;n 次独立重复试验中成功次数 X ~ B(n, p)。
- P(X = k) = C(n, k)pᵏ(1 − p)ⁿ⁻ᵏ,分布列必须列全 k = 0 到 n,且全部概率之和为 1。
- E(X) = np 是加权平均:n 次试验平均成功 np 次;D(X) = np(1 − p),固定 n 时 p = 0.5 方差最大。
- 教材与课标把 E(X) 称为均值(期望)、D(X) 称为方差;σ = √D(X) 为标准差。

## 公式与结论
- E(X) = np;D(X) = np(1 − p);一般分布列也满足 D(X) = E(X²) − [E(X)]²。
- 典型算例:n = 10、p = 0.3 → E = 3、D = 2.1、P(X = 3) ≈ 0.2668(峰值附近)。
- p = 0.5 时分布左右对称;p ≠ 0.5 时峰偏向一侧,峰值位置在 np 附近。
- 二项分布与超几何分布同在 7.4 节,前者来自有放回(独立重复),后者来自不放回抽样,前提不同。
