## 演示构成
- 散点图 + 拟合直线同坐标系:样本点用实心圆点,回归直线用实线,样本中心点 (x̄, ȳ) 单独标记。
- 残差可视化:每个样本点到拟合直线的竖直偏差用线段画出,正残差与负残差分色,面板显示残差平方和。
- 数据面板显示 n、x̄、ȳ、Σ(xᵢ−x̄)(yᵢ−ȳ)、Σ(xᵢ−x̄)²、b̂、â、r,全部由当前数据实时算出。
- 预测输入框:输入 x₀ 显示代入过程 ŷ = b̂x₀ + â 的数值,并在图上标出预测点。

## 操作要点
- 演示须呈现列表计算过程(先算 x̄、ȳ 与三个和 Σ(xᵢ−x̄)(yᵢ−ȳ)、Σ(xᵢ−x̄)²、Σ(yᵢ−ȳ)²,再代入公式),不得直接跳到回归方程结果。
- b̂、â、r 必须由公式对当前数据独立重算并显示中间量,页面数值不得手工写死,审查器按 b̂ = Σ(xᵢ−x̄)(yᵢ−ȳ) ÷ Σ(xᵢ−x̄)² 与 â = ȳ − b̂x̄ 对拍。
- 残差必须按 eᵢ = yᵢ − ŷᵢ 用观测值减预测值计算,正负号要保留,不得显示绝对值冒充残差。
- r ≈ 0 或散点明显不呈线性趋势时,须提示「线性相关不明显,直线拟合仅作参考」,不得强行展示回归直线并宣称强相关。
- 预测值要注明「点预测」,x₀ 远离原数据范围时提示外推不可靠。
