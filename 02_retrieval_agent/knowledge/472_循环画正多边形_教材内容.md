## 核心概念
- 正多边形每条边相等、每个内角相等；沿边走完一圈回到起点时，方向恰好转回出发时的朝向，方向改变量的总和恒为 360°。
- 程序里每次转的是外角：外角 = 360° ÷ n；内角 = 180° − 外角，两者不要混写。
- 循环体 = 「前进一段边长 → 转过一个外角」，循环次数 = 边数 n；少执行一次轨迹不闭合，多执行一次沿首边重走。
- n 越大外角越小，n 足够大（如 36 边）时轨迹近似圆——「重复次数与转角共同决定形状」的直观体验。

## 公式与结论
- 每次转角 = 360° ÷ n，总转角 = n × (360° ÷ n) = 360°，与边长无关。
- 外角与边数乘积恒为 360°：n 翻倍，每次转角减半（n=3→120°，n=6→60°）。
- 轨迹闭合需三者同时正确：执行次数 = n、每次转角 = 360° ÷ n、每段边长相等；任一出错即不闭合或不成正多边形。
- 重复命令（如 REPEAT n [FD 步长 RT 360/n]）是循环结构的指令化表达：方括号内为循环体，前面的数为循环次数。
