## 核心概念
- 动量 p = mv,是矢量,方向与速度方向相同,单位 kg·m/s;运算必须先取正方向。
- 动量守恒的条件:系统不受外力或所受外力的矢量和为零;碰撞、爆炸过程中内力远大于外力,可近似认为守恒。
- 弹性碰撞:动量守恒且动能守恒;非弹性碰撞:动量守恒、动能有损失;完全非弹性碰撞:碰后合为一体(共速),动能损失最大。
- 等质量两物体弹性正碰时交换速度:碰后甲静止、乙以甲原来的速度运动。
- 反冲现象:系统内两部分向相反方向运动,总动量保持不变,火箭、喷气式飞机是典型应用。

## 公式与结论
- 一维碰撞守恒式 m₁v₁ + m₂v₂ = m₁v₁′ + m₂v₂′,代入数值前必须统一正方向、反向速度取负号。
- 完全非弹性碰撞的共同速度 v′ = (m₁v₁ + m₂v₂)/(m₁ + m₂)。
- 弹性正碰公式:v₁′ = (m₁−m₂)v₁/(m₁+m₂) + 2m₂v₂/(m₁+m₂),v₂′ 与之对称;v₂ = 0 时 v₁′ = (m₁−m₂)v₁/(m₁+m₂)、v₂′ = 2m₁v₁/(m₁+m₂)。
- 动量守恒不等于动能守恒:非弹性碰撞中损失的动能转化为内能等;判断碰撞是否可能发生,还要看碰后总动能不大于碰前总动能。
