## 核心概念
- 化学反应前后元素种类和原子数守恒；离子反应还要满足电荷守恒。
- 化学式下标属于物质组成，不能通过修改下标来配平方程式。
- 同一方程式的系数可同比放大仍满足守恒，规范表示应约成最简正整数比。
- 离子电荷必须与物种绑定处理；不能只检查原子数而漏掉电荷。

## 公式与结论
- H₂ + O₂ → H₂O 的最简配平结果为 2H₂ + O₂ → 2H₂O。
- Fe + O₂ → Fe₂O₃ 的最简配平结果为 4Fe + 3O₂ → 2Fe₂O₃。
- 配平结果必须逐元素复算；离子方程式额外复算总电荷。
- 若输入物质无正整数守恒解、存在多解或超出解析能力，应返回不可解/不支持，不能猜系数。
