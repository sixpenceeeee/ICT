## 可调参数
A(0.5~5)、ω(0.5~4)、φ(−π~π)、单位圆联动开关、五点标注开关、参考虚线 y = Asin(ωx) 开关

## 可复算量
- 在采样点上用 y = A·sin(ωx + φ) 独立重算函数值,与页面曲线读数比对(容差 0.01)。
- 周期 T 是否等于 2π/ω,与页面标尺一致(容差 0.01)。
- 最大值、最小值是否为 A 与 −A(容差 0.01)。
- 五点法五个 x 坐标是否等于 (kπ/2 − φ)/ω(k = 0,1,2,3,4)(容差 0.01)。
- 零点是否落在 x = (kπ − φ)/ω(容差 0.01)。

## 常见错误
- 把 T = 2π/ω 算成 2πω(ω = 2 时误报周期约 12.57)。
- 认为振幅 A 是「峰到谷的距离」(峰谷距是 2A)。
- 平移方向弄反:φ > 0 时 y = sin(x + φ) 向左平移,不是向右。
- 把 ωx + φ 标注成「初相」。
