## 核心概念
- 等差数列:aₙ₊₁ − aₙ = d(公差,d 可为 0 或负);等比数列:aₙ₊₁ ÷ aₙ = q(公比,q ≠ 0,各项均非零)。
- 等差前 n 项和来自高斯配对(倒序相加):每对 (a₁ + aₙ) 相等,共 n ÷ 2 对,得 Sₙ = n(a₁ + aₙ) ÷ 2。
- 等比前 n 项和来自错位相减:推导中除以 (1 − q),故 q = 1 时公式失效,必须改用 Sₙ = na₁。
- aₙ 与 Sₙ 的关系:aₙ = Sₙ − Sₙ₋₁(n ≥ 2),n = 1 时 a₁ = S₁。

## 公式与结论
- 等差 Sₙ 两式等价:Sₙ = n(a₁ + aₙ) ÷ 2 = na₁ + n(n − 1)d ÷ 2。
- 等比 Sₙ = a₁(1 − qⁿ) ÷ (1 − q) = a₁(qⁿ − 1) ÷ (q − 1)(q ≠ 1),分子分母符号必须配套。
- 典型算例:等差 2 + 5 + … + 29 共 10 项 = 155;等比 1 + 2 + … + 512 共 10 项 = 1023。
- 通项 aₙ = a₁ + (n − 1)d、aₙ = a₁qⁿ⁻¹;等比数列任意一项非零,含 0 项的数列必不是等比数列。
