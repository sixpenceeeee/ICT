## 演示构成
- 矩形动态演示:给定周长 2(a + b) = C(滑块调 C),拖动一边长 a,实时并排显示面积 ab 与上界 (C/4)² 的对比柱。
- 等号点高亮:a = b = C/4 时矩形变为正方形并高亮「取等」标记,面积柱恰触到上界。
- 反向模式:给定面积 ab = P,实时显示周长 2(a + b) 与下界 4√P,正方形时触底。
- 数值面板显示 a、b、a + b、√ab、2√ab 与当前面积/周长对理论界的差值。

## 操作要点
- 拖动 a 时必须实时显示 2√ab 与 a + b 的大小关系,审查器按 ab ≤ ((a+b)/2)² 与等号条件 a = b 对拍。
- 等号点必须可复算:a = b 时页面显示「取等」,a ≠ b 时不得显示最值达成状态。
- 面积上界由 ((a+b)/2)² 独立重算,不得用拖动过程中见到的最大面积冒充上界。
- 「面积一定求最短周长」模式同样先固定 P 再扫 a,正方形点周长恰为 4√P,读数误差不大于 0.5%。
- 约束条件要显式呈现(周长定值 C 或面积定值 P),不得出现「a、b 都在变还宣称和为定值」的状态。
