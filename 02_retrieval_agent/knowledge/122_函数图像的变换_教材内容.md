## 核心概念
- 左右平移:y = f(x − h)(h > 0 时图象右移 h 个单位);y = f(x + h) 左移——「x 加左减右」,作用在 x 上。
- 上下平移:y = f(x) + k(k > 0 上移);作用在函数值上,对称轴与开口大小不变。
- 纵向伸缩:y = af(x),纵坐标变为原来的 a 倍;a < 0 时还关于 x 轴翻折。
- 横向伸缩:y = f(ωx),横坐标变为原来的 1/ω 倍;ω > 1 压缩、0 < ω < 1 拉伸。
- 组合变换 y = af(x − h) + k:原图象上每点 (x₀, y₀) 映到 (x₀ + h, a·y₀ + k),先定点映射再连线。
- 变换顺序影响结果:y = f(2x − 1) = f(2(x − ½)),应「右移 ½」而非「右移 1」;只有先提出 x 的系数,平移量才正确。

## 公式与结论
- 关键点映射表:f(x) = x² 的点 (0,0)、(1,1)、(2,4)、(−1,1) 在 y = 2f(x − 1) + 3 下依次变为 (1,3)、(2,5)、(3,11)、(0,5)。
- 验算:y = 2(x − 1)² + 3 在 x = 2 时 y = 2×1 + 3 = 5,x = 3 时 y = 2×4 + 3 = 11,与映射表一致。
- 顶点迁移:y = af(x − h) + k 把 y = ax² 的顶点 (0,0) 变为 (h, k)。
- 对称轴同步:y = f(x − h) 的对称轴由 x = 0 变为 x = h;上下平移不改变对称轴。
- y = −f(x) 关于 x 轴翻折、y = f(−x) 关于 y 轴翻折,两者不是同一种变换。
