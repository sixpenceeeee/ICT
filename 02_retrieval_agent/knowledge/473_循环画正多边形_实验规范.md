## 演示构成
- 角色按「前进 → 转角」逐步运动，画出多边形运动轨迹，轨迹线保留不擦除。
- 每个顶点处标注本次转角度数及其来源式（360° ÷ n 的计算过程），角色朝向用箭头显示。
- 状态面板：边数 n、边长、每次转角、已执行循环次数、累计转角、是否闭合。
- 单步 / 连续两种播放模式，单步一次只走一条边加一次转角。

## 操作要点
- 每次循环只做「前进一段、转一次角」两件事，不得一次连走多条边或跳过转角。
- 转角必须展示 360° ÷ n 的计算过程，不能只给结果。
- 累计转角实时累加，结束时显示 360° 并演示「转回初始朝向」，让闭合可见。
- 至少演示 n = 3、4、6 三组，对比「边数增大 → 每次转角变小」；可加 36 边形近似圆。
- 全程转向方向一致（全左转或全右转），中途变向即为错误。
- 审查判据：用 n 复算每次转角与循环次数（转角 = 360° ÷ n，轨迹边数 = 循环次数 = n）。
