## 可调参数
n(1~20)、p(0.01~0.99,步长 0.01)、期望标注开关、σ 区间开关、试验模拟开关

## 可复算量
- ΣP(k) = 1(k = 0…n,容差 0.001)。
- 每根柱 P(X = k) = C(n, k)pᵏ(1 − p)ⁿ⁻ᵏ 独立重算(容差 0.001)。
- E(X) = np 与柱状图加权平均 Σk·P(k) 相等(容差 0.01)。
- D(X) = np(1 − p) 与 Σ(k − np)²P(k) 相等(容差 0.01);σ = √D(容差 0.01)。

## 常见错误
- 漏掉组合数 C(n, k)。
- 认为 p 越大方差越大(固定 n 时方差在 p = 0.5 处最大)。
- 把「10 次试验恰好成功 3 次」与「前 3 次成功」混淆(前者多乘 C(10, 3))。
- E 只取峰值位置而不做加权平均。
- 各柱概率加起来不等于 1 也不检查。
