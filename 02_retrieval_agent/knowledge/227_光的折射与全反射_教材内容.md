## 核心概念
- 折射定律：光从真空射入介质时 sinθ₁/sinθ₂ = n，θ₁、θ₂ 都从法线量起；光路可逆。
- 折射率 n = c/v，反映介质对光的偏折能力；n 越大，光在介质中速度越小、偏折越厉害。
- 光密介质与光疏介质是相对的：n 大的为光密。全反射只能发生在光从光密介质射向光疏介质时。
- 全反射两条件缺一不可：①光从光密介质射向光疏介质；②入射角大于或等于临界角 C，sinC = 1/n。
- 光导纤维：内芯折射率大于外套（包层），光在内芯与包层界面不断全反射向前传播。
- 水中气泡、水下向上看水面像「亮镜」、海市蜃楼等都与全反射有关；弯曲水柱导光是全反射的直观演示。

## 公式与结论
- n = sinθ₁/sinθ₂ = c/v；n 真空取 1，空气约取 1.0。
- sinC = 1/n：玻璃 n = 1.5 → C ≈ 41.8°；水 n = 1.33 → C ≈ 48.8°；金刚石 n = 2.42 → C ≈ 24.4°。
- 算例：玻璃 n = 1.5，θ₁ = 45° 入射 → θ₂ ≈ 28.1°；水→空气 θ₁ = 45° → θ₂ ≈ 70.1°（未到临界），θ₁ = 50° → 全反射。
- 从空气射入玻璃，入射角再大也不会全反射（方向条件不满足）。
