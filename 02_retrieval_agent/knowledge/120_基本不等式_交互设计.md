## 可调参数
周长定值 C(4~100)或面积定值 P(1~625)二选一、边长 a(0.1~C/2)、显示等号点开关、对比柱开关

## 可复算量
- 给定 C:ab ≤ (C/4)² 是否恒成立,且 a = b = C/4 时取等(容差 0.01)。
- 给定 P:2(a + b) ≥ 4√P 是否恒成立,且 a = b = √P 时取等(容差 0.01)。
- 页面显示的 2√ab 与 a + b 的大小关系方向是否正确(容差 0.01)。
- 最值达成状态与等号条件 a = b 是否一致(容差 0.005)。

## 常见错误
- 认为 a + b ≥ 2√ab 对任意实数 a、b 都成立(要求 a、b 均为非负)。
- 求出 ab ≤ 25 就答「最大值 25」,不检验 a = b 是否可取。
- 把「积定和最小」与「和定积最大」两句话用反。
- 在 x + 1/x 中不讨论 x < 0,直接写最小值 2。
