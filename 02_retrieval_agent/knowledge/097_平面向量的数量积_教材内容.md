## 核心概念
- 数量积 a·b = |a||b|cosθ,结果是一个数量(实数),不是向量;θ 是 a 与 b 的夹角,范围 [0°, 180°]。
- 两个非零向量垂直 ⇔ a·b = 0;θ = 0°(同向)时 a·b = |a||b|,θ = 180°(反向)时 a·b = −|a||b|。
- b 在 a 上的投影向量 = (a·b ÷ |a|²)·a,方向由 cosθ 符号决定,可与 a 同向或反向;|b|cosθ 是投影向量的模(带符号)。
- 物理背景:恒力 F 使物体位移 s,做功 W = F·s = |F||s|cosθ,功就是数量积的物理原型。

## 公式与结论
- 坐标式:a = (x₁, y₁)、b = (x₂, y₂) 时 a·b = x₁x₂ + y₁y₂,与定义式恒等。
- cosθ = a·b ÷ (|a||b|)(a、b 均非零);|a| = √(a·a)。
- 典型算例:a = (2, 0)、b = (1, √3),夹角 60°,a·b = 2,b 在 a 上的投影向量 (1, 0)。
- a·b 只与模长和夹角有关,与坐标系选择无关(坐标式算出的就是定义式的值)。
