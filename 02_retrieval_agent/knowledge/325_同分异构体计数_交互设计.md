## 可调参数
分子式预设（C₄H₁₀ / C₅H₁₂ / C₆H₄Cl₂ / C₂H₆O / C₄H₈）、烷烃碳原子数 n（1~6）、异构类型切换（碳架异构/位置异构/官能团异构）、结构显示切换（结构简式/键线式/球棍模型）、枚举单步推进开关

## 可复算量
- C₄H₁₀ 碳架异构计数 = 2（正丁烷、异丁烷），容差 0。
- C₅H₁₂ 碳架异构计数 = 3（正戊烷、异戊烷、新戊烷），容差 0。
- C₆H₄Cl₂ 位置异构计数 = 3（邻、间、对二氯苯），容差 0。
- C₂H₆O 官能团异构计数 = 2（乙醇、二甲醚），容差 0。
- C₄H₈ 限定开链烯烃的位置异构计数 = 2（1-丁烯、2-丁烯），容差 0。
- 每个枚举结构的原子组成与给定分子式一致（如 C₅H₁₂ 各结构碳 5、氢 12），容差 0；列表行数与计数器显示相等，容差 0。

## 常见错误
- 漏掉对称性归并：把 2-甲基丁烷写成「3-甲基丁烷」另算一种（实为同一结构）。
- 认为 C₅H₁₂ 只有直链与一个支链两种，漏掉新戊烷 C(CH₃)₄。
- 写 C₂H₆O 时只写醇不写醚，漏掉官能团异构。
- 把 1-丁烯与 2-丁烯当成同一种（双键位置不同，是位置异构）。
- 不限定链烃时枚举 C₄H₈ 只写烯烃，漏掉环丁烷、甲基环丙烷。
