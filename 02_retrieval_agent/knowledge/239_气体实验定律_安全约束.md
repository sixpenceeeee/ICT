## 安全边界
- 虚拟气缸压强上限 5×10⁶ Pa：逼近超限时提示活塞冲出、容器爆裂风险，只作警示不展开真实操作。
- 温度范围 3~1000 K，不出现 0 K 或负热力学温度；提示绝对零度只能逼近、不能达到。
- 不生成氧气瓶、高压锅、打气筒爆胎等真实高压容器的操作参数，只做原理级演示。

## 禁止生成
- 把摄氏温度直接代入 pV/T = 常量或任何比例式。
- 声称气体可以被降温到 0 K。
- 把三条实验定律用于漏气、充气等质量变化情形而不作说明。
- 把 p-V 图上的等温线画成过原点的直线。
