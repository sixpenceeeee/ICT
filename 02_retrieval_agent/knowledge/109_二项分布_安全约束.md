## 数值边界
- n ∈ [1, 20];p ∈ (0.01, 0.99),步长 0.01;p = 0 或 1 时退化为确定值,必须拦截并提示。
- 概率显示保留 4 位小数,E、D 保留 2~3 位小数;C(n, k) 用精确整数计算,禁止浮点连乘误差累积。
- ΣP(k) 偏离 1 超 0.001 即判定数值实现有错,停止渲染。

## 禁止生成
- 把 P(X = k) 写成 pᵏ(1 − p)ⁿ⁻ᵏ(漏组合数 C(n, k))。
- 把 E(X) 写成 n(1 − p),或把 D(X) 写成 np²(应为 np(1 − p))。
- 柱状图纵轴不从 0 开始或柱高不按概率比例,造成视觉误导。
- 声称二项分布总是对称的(仅 p = 0.5 对称)。
- 把超几何分布、正态分布的数据套用二项分布公式演示。
