## 核心概念
- 导数是平均变化率 [f(x₀+Δx) − f(x₀)] ÷ Δx 在 Δx → 0 时的极限,即瞬时变化率;f′(x₀) 是一个数,f′(x) 是导函数,两者不是一回事。
- 导数的几何意义:f′(x₀) 是曲线 y = f(x) 在点 (x₀, f(x₀)) 处切线的斜率。
- 切线是割线的极限位置:过曲线上 P、Q 两点作割线,当 Q 沿曲线无限趋近 P 时,割线 PQ 的极限位置就是切线。
- 教材 5.2 公式表内可直接求导的基本初等函数:y = c、y = x、y = x²、y = x³、y = 1/x、y = √x((x²)′ = 2x,(x³)′ = 3x²,(1/x)′ = −1/x²)

## 公式与结论
- 切线方程由点斜式直接写出:y − f(x₀) = f′(x₀)(x − x₀),其中切点 (x₀, f(x₀)) 必须在曲线上。
- 典型算例:f(x) = x² 在 x₀ = 1 处斜率 2,切线 y = 2x − 1。
- 割线斜率随 Δx 减小逼近切线斜率:f(x) = x² 时前向差商 (f(1.1) − f(1)) ÷ 0.1 = 2.1,Δx → 0 时趋于 2。
- 切线在切点附近与曲线贴合,但不要求与曲线只有一个交点(如 y = x³ 在原点处的切线穿过曲线)。
