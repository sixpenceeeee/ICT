## 可调参数
R、G、B 滑块（各 0~255）、取整方式（round / int）、预设检验色块（红/绿/蓝/白/黑/黄）、单像素/整图模式

## 可复算量
- 取整前 Gray 是否等于 0.299R + 0.587G + 0.114B（容差 ±0.05）。
- 取整后结果是否等于所选规则作用在取整前值上（容差 0）。
- R=G=B=v 时 Gray 是否等于 v（容差 0）。
- 权重和是否等于 1.000（容差 ±0.001）。
- 纯色检验（round 口径）：红 76、绿 150、蓝 29（容差 ±1，int 口径绿为 149）。

## 常见错误
- 忘记加权，直接三值相加除以 3。
- 权重顺序记错（把 0.587 配给红通道）。
- 忽略取整规则差异，认为 round 与 int 必得同一值。
- 认为灰度图仍是三个通道。
- 认为颜色越鲜艳灰度值越大（灰度值只由加权和决定，与「鲜艳」无单调关系）。
