## 核心概念
- 中和滴定是用已知浓度的标准溶液测定未知浓度溶液的定量实验,依据是恰好中和时 n(H⁺)=n(OH⁻)。
- 强酸强碱恰好中和时溶液呈中性:室温下由 Kw=1×10⁻¹⁴ 得 c(H⁺)=c(OH⁻)=1×10⁻⁷ mol/L,即等当点 pH=7。
- 滴定过程 pH 变化呈「缓—陡—缓」:大部分体积内变化缓慢,等当点附近 ±0.02 mL 内发生突跃。
- 指示剂选择:变色范围全部或部分落在突跃范围内;强碱滴定强酸可用酚酞(无色→浅红)或甲基橙,石蕊不用于定量滴定。
- 仪器:酸式滴定管(玻璃旋塞,盛酸性/氧化性溶液)、碱式滴定管(乳胶管玻璃珠,盛碱性溶液),读数至 0.01 mL。

## 公式与结论
- 室温 25℃:Kw = c(H⁺)×c(OH⁻) = 1×10⁻¹⁴,pH+pOH=14,中性 pH=7。
- 一元酸碱等当点关系:c(待测) = c(标准)×V(标准)÷V(待测)。
- 示例曲线数据(0.1000 mol/L NaOH 滴定 20.00 mL 0.1000 mol/L HCl):V=0 → pH=1.00;V=19.98 mL → pH≈4.30;V=20.00 mL → pH=7.00;V=20.02 mL → pH≈9.70。
- 读数误差直接进入结果:滴定体积 ±0.02 mL 对应浓度 ±0.1%(以 20.00 mL 为基准)。
