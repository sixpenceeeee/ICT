## 可调参数
步骤推进（检查气密性→装固体→加稀盐酸→收集→验满→性质检验）、药品选择对照（稀盐酸/稀硫酸/浓盐酸）、错误操作对照开关

## 可复算量
- CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑ 两边各元素原子数是否相等（Ca/C/H/O/Cl = 1/1/2/3/2），容差 0。
- CO₂ + Ca(OH)₂ → CaCO₃↓ + H₂O 两边氧原子数是否相等（2+2 → 3+1），容差 0。
- 装置与理由是否匹配：二氧化碳能溶于水 → 不用排水法；密度比空气大 → 向上排空气法。
- 验满（燃着木条平放瓶口）与检验（通入澄清石灰水）的方法是否与对象对应。

## 常见错误
- 认为稀硫酸、浓盐酸都能用于制取二氧化碳。
- 验满时把木条伸进瓶内。
- 长颈漏斗下端悬在液面以上，气体从漏斗口跑掉。
- 认为二氧化碳可以用排水法收集（它能溶于水且与水反应）。
