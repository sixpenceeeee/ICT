## 核心概念
- 分数的意义:把单位「1」平均分成若干份,表示这样的一份或几份的数;一个物体的几分之几与一堆物体的几分之几都基于「平均分」,不平均分不能写分数。
- 分数单位:把单位「1」平均分成若干份,表示其中一份的数,只由分母决定——3/4 的分数单位是 1/4,3/4 里有 3 个 1/4;分母越大,分数单位越小。
- 同分母分数加减:分数单位相同,直接把分子相加减、分母不变——1/5 + 2/5 = 3/5,就是 1 个 1/5 加 2 个 1/5 等于 3 个 1/5。
- 异分母分数加减:分数单位不同,不能直接相加减,要先通分化成同分母,再按同分母加减计算。

## 公式与结论
- 通分:把异分母分数分别化成和原来分数相等的同分母分数,公分母一般取原来几个分母的最小公倍数,先约分再通分可减小数字。
- 通式 a/b ± c/d = (ad ± bc)/bd (b、d ≠ 0);结果要化成最简分数:分子分母同除最大公因数,22/24 = 11/12。
- 典型算例:3/4 + 1/6 通分 9/12 + 2/12 = 11/12;5/6 − 3/10 通分 25/30 − 9/30 = 16/30 = 8/15(gcd(16,30)=2)。
- 带分数与假分数互化、分数与小数互化(能除尽的情形)是本组单元的常考配套技能,加减结果超过 1 时用假分数或带分数表达。
