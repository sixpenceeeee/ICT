## 演示构成
- 坐标系中绘制函数曲线 f(x),切点 P(x₀, f(x₀)) 实心标记,过 P 的切线高亮着色,旁边标注斜率 k = f′(x₀) 的数值。
- 割线演示:曲线上取动点 Q(x₀+Δx, f(x₀+Δx)),显示割线 PQ 及其斜率,拖动 Δx → 0 观察割线逼近切线的过程。
- 数值面板四行读数:x₀、f(x₀)、f′(x₀)、切线方程,随切点拖动实时刷新。
- 多点模式:同一坐标系在不同 x₀ 处同时画出切线,直观看到「斜率随点变」。

## 操作要点
- 「求切线方程」交互必须按考试评分步骤走:先求 f′(x)、代入 x₀ 得斜率、再写点斜式 y − f(x₀) = f′(x₀)(x − x₀),三步缺一不可。
- 切点必须画在曲线上并核对 y₀ = f(x₀);斜率标注必须等于 f′(x₀),不得用割线两点读数的平均代替。
- Δx = 0 时不计算差商,提示「Δx 为 0 无意义」;Δx 最小步长 0.01。
- 「在某点处的切线」与「过某点的切线」是两类题:过曲线外点的切线要先设切点再解方程,不得把该点直接当切点代入。
