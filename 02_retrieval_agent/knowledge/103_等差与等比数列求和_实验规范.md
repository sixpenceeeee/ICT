## 演示构成
- 坐标系中画数列散点(n, aₙ),等差/等比切换;每个散点下方叠加竖条,竖条面积表示该项,累计高度表示 Sₙ。
- 求和面积面板:等差模式演示「(a₁ + aₙ) × n ÷ 2」的矩形拼合,配对条目(a₁ 与 aₙ、a₂ 与 aₙ₋₁)成对高亮,每对和恒等。
- 参数面板显示 a₁、d 或 q、n 与实时算出的 aₙ、Sₙ,通项公式与求和公式随参数同步重写。
- 「倒序相加」「错位相减」推导步骤演示开关,逐行高亮。

## 操作要点
- 求和前必须先判类型与特殊值:等比先查 q = 1(改走 Sₙ = na₁ 分支),等差允许 d = 0(常数列)。
- Sₙ 必须由两式各算一遍互检(审查器对拍口径),差超 0.01 判页面错误,不得手工写死。
- 散点逐点代入通项公式复核,散点纵坐标与 aₙ 一致(容差 0.01)。
- n 增减时散点、竖条与 Sₙ 读数同步刷新,禁止出现散点个数与 n 不一致的画面。
