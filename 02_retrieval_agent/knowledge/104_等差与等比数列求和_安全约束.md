## 数值边界
- n ∈ [1, 50];d ∈ [−10, 10];q ∈ [−5, 5] 且 q ≠ 0,a₁ ≠ 0。
- q = 0 必须拦截(等比数列公比非零);|q| > 5 或 n 过大导致 Sₙ 溢出时提示并截断。
- 显示保留 2 位小数;q 为负时各项正负交替,坐标轴必须能显示负值,Sₙ 按公式带符号计算,不取绝对值。

## 禁止生成
- q = 1 时仍代入 Sₙ = a₁(1 − qⁿ) ÷ (1 − q)(分母为 0)。
- 等差展开式把 d 的系数写成 n(n + 1) ÷ 2(应为 n(n − 1) ÷ 2)。
- 把含 0 项的数列判成等比数列(公比非零是前提)。
- 通项写成 aₙ = a₁ + nd(应为 a₁ + (n − 1)d)。
- 等比求和分子分母符号不配套(如 Sₙ = a₁(1 − qⁿ) ÷ (q − 1))。
