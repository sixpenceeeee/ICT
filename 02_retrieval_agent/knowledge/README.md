# 本地教学知识原文

## 职责

保存按主题与类别组织、供 `kb.py` 检索的 Markdown 知识文本。

## 内容

`01_课程标准.md` 等早期电路文件、`06–10_浮力_*.md` 与后续 `NNN_主题_类别.md` 记录课标、教材、规范、安全和交互知识。正文知识文件含 `类别`、`主题`、`来源` frontmatter。

## 层级关系

上层：[知识检索 Agent](../README.md)；源数据和渲染办法见 [seed](../seed/README.md)。检索结果写入 [output](../output/README.md)。

## 边界与纪律

本 README 是目录说明，加载器按文件名排除它；不要将无 frontmatter 的草稿混入知识文件。新增知识优先改 `seed/*_kb.py` 再生成，保留既有手写电路与浮力原文。
