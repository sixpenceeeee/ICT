## 输入边界
- R、G、B 取 0~255 的整数；负数或大于 255 报错。
- 权重固定为 0.299 / 0.587 / 0.114，不提供改权重的入口。
- 演示图像素总数 ≤ 100 万（大图先缩放，避免逐像素演示卡顿）。

## 禁止生成
- 用 (R+G+B) ÷ 3 简单平均却标注为「标准灰度化公式」。
- 把权重写成 0.3 / 0.59 / 0.11 后声称与标准公式结果完全一致（会引入偏差）。
- 权重和大于 1（如末项误写 0.144）导致 Gray 越出 255。
- 声称灰度化可逆或无损（原彩色信息不可恢复）。
- 对已是灰度的图像再按三通道读取并乘权重（重复计算）。
