## 演示构成
- 圆 O 与弦 AB,过圆心的直径 CD 垂直于 AB,垂足 E 标直角符号;AE=EB 与两对弧相等的标记同步高亮。
- 同弧双角标注:圆心角 ∠AOB 与圆周角 ∠ACB 用同色弧标出所对弧,拖动圆周上的动点 C,两个角度实时刷新。
- 数值面板显示 r、d、弦长 a 与 (a/2)² + d² 的实时计算值,与 r² 并排对照。
- 圆内接四边形模式:四个顶点可在圆上拖动,两组对角实时显示且和恒为 180°。

## 操作要点
- 垂径演示必须同时高亮「过圆心」「垂直」两个条件与「平分弦」「平分弧」两个结论;条件缺一时不得显示相等结论,对应课标「探索并证明」的推理要求。
- 圆周角演示中动点 C 不得与 A、B 重合:C 落到 A、B 上时角度退化,要暂停刷新并提示。
- 动点 C 从劣弧一侧跨到优弧一侧时,必须同步切换「所对弧」的标注,否则 ∠ACB 与 ∠AOB/2 会出现矛盾读数。
- 拖动改变 d 时弦长按 a = 2√(r² − d²) 由审查器独立重算对拍,页面数值不得手工写死。
