## 课标定位
属于高中「函数」主题(选择性必修,单元名「数列」)。数列是定义域为正整数集的特殊函数,求和公式是通项的累积;课标要求「探索并掌握」前 n 项和公式并理解通项与前 n 项和的关系,还要求体会等差数列与一元一次函数、等比数列与指数函数的联系。

## 内容与学业要求
- 通过日常生活和数学中的实例,了解数列的概念和表示方法(列表、图象、通项公式),了解数列是一种特殊函数。(内容要求·数列概念)
- 探索并掌握等差数列的前 n 项和公式,理解等差数列的通项公式与前 n 项和公式的关系。(内容要求·等差数列②)
- 探索并掌握等比数列的前 n 项和公式,理解等比数列的通项公式与前 n 项和公式的关系。(内容要求·等比数列②)
- 体会等差数列与一元一次函数的关系、等比数列与指数函数的关系。(内容要求·等差数列④、等比数列④)
