## 数值边界
- a、b 限定为正数(0.1~50),a ≤ 0 或 b ≤ 0 时基本不等式不适用,必须拦截并提示。
- 周长定值 C 限定 4~100,保证 a、b 有意义且在视口内;显示保留 2 位小数。
- √ab 与面积分别按公式独立计算显示,不得用 ((a+b)/2)² 直接冒充当前面积。
- 面积与上界的差值显示保留 4 位小数,避免取等点附近舍入误差掩盖「是否触界」。

## 禁止生成
- 把 a + b ≥ 2√ab 用到 a、b 为负数或一正一负的情形(√ab 无意义或方向反转)。
- 漏掉取等条件直接写「最小值/最大值是……」(等号取不到时该值只是下界/上界,不是最值)。
- 把 a² + b² ≥ 2ab 与 √ab ≤ (a+b)/2 的适用条件混用(前者对任意实数成立,后者要求 a、b 均为非负)。
- 在 a + b 不是定值时直接套 ab ≤ ((a+b)/2)² 求最值(须先构造定值)。
- 声称「周长一定时矩形面积最大是长边越长越好」(应为正方形)。
