## 核心概念
- 正弦曲线 y = sin x 过 (0, 0),周期 2π,最大值 1、最小值 −1;五点法用相位 0、π/2、π、3π/2、2π 五个关键点定形。
- y = Asin(ωx + φ) 中:A 控制振幅(最大值 A、最小值 −A),ω 控制周期(T = 2π/ω,ω 越大波形越密),φ 控制左右平移(y = Asin(ωx) 向左平移 φ/ω)。
- 相位是 ωx + φ,初相是 x = 0 时的相位 φ,两者不能混称。
- 周期现象模型:匀速圆周运动、交变电流、简谐运动都用 y = Asin(ωx + φ) 刻画(教材 5.6.1 匀速圆周运动的数学模型;阅读与思考 振幅、周期、频率、相位)。

## 公式与结论
- 周期 T = 2π ÷ ω;频率 f = 1 ÷ T。
- 零点 x = (kπ − φ) ÷ ω(k 为整数);最大值点在相位 = π/2 + 2kπ 处。
- 典型算例:y = 2sin(2x + π/3) 的五点:x = −π/6、π/12、π/3、7π/12、5π/6,y = 0、2、0、−2、0。
- y = sin x 的图象经「振幅变换(×A)→ 周期变换(1/ω)→ 平移变换(φ/ω)」得到 y = Asin(ωx + φ)。
