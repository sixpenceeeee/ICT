## 核心概念
- 一次函数 y = kx + b (k ≠ 0) 的图象是一条直线;k > 0 时 y 随 x 增大而增大,k < 0 时 y 随 x 增大而减小;b 是图象与 y 轴交点的纵坐标。
- 每个二元一次方程都能变形为 y = kx + b 的形式,对应平面直角坐标系里的一条直线;两个方程对应两条直线。
- 方程组的解就是两条直线交点的坐标:交点同时满足两个方程;这是「体会一次函数与二元一次方程的关系」的核心。
- k1 = k2 且 b1 ≠ b2 时两直线平行、没有交点,对应方程组无解;k1 = k2 且 b1 = b2 时两直线重合,方程组有无穷多组解。

## 公式与结论
- 交点坐标公式:x* = (b2−b1)/(k1−k2),y* = k1x* + b1(k1 ≠ k2);等价地 y* = (k1b2−k2b1)/(k1−k2)。
- 典型算例:y = 2x+1 与 y = −x+4 交于 (1,3);回代 2×1+1 = 3、−1+4 = 3 都成立,方程组 {2x−y=−1, x+y=4} 的解就是 x=1、y=3。
- 图象法求的是近似解(读图有读数误差),代入/加减消元法求的是精确解,两者互相验证。
- |k1−k2| 越小交点越远:|k1−k2| = 0.1 时交点横坐标可达几十,视口要随之调整或标注「视口外」。
