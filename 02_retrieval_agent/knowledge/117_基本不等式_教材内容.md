## 核心概念
- (a+b)/2 叫算术平均数,√ab 叫几何平均数;基本不等式说的是「算术平均数不小于几何平均数」。
- 证明是两行:(√a − √b)² ≥ 0 展开得 a + b − 2√ab ≥ 0(a > 0,b > 0),等号当且仅当 a = b 成立。
- 推论 ab ≤ ((a+b)/2)²(a, b > 0);更强的 a² + b² ≥ 2ab 对任意实数都成立,等号 a = b。
- 和定积最大:a + b = S 为定值时 ab ≤ S²/4,当 a = b = S/2 取等——周长一定的矩形中,正方形面积最大。
- 积定和最小:ab = P 为定值时 a + b ≥ 2√P,当 a = b = √P 取等——面积一定的矩形中,正方形周长最短。
- 求最值要同时满足「一正、二定、三相等」:a、b 为正,和或积为定值,且等号取得到。

## 公式与结论
- x + 1/x ≥ 2(x > 0),取等 x = 1;x < 0 时 x + 1/x ≤ −2,取等 x = −1。
- 典型算例:周长 20 的矩形 ab ≤ 25,a = 2、b = 8 时面积 16,a = 4、b = 6 时 24,a = b = 5 时 25。
- 典型算例:面积 36 的矩形 a + b ≥ 12,周长 2(a + b) ≥ 24,正方形 a = b = 6 时最短。
- 和不是定值时不能直接用:须先恒等变形构造定值(如配凑系数、换元),这是考试里最常见的失分点。
- 等号条件必须检验:解出 a = b 与约束条件有公共解,最值才存在,否则该界只能称上界/下界。
