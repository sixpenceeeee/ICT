## 数值边界
- A ∈ [0.5, 5],ω ∈ [0.5, 4](ω = 0 无周期,必须拦截并提示「ω = 0 时不是正弦型函数」),φ ∈ [−π, π]。
- x 采样范围固定 [−2π, 2π],步长 0.05;显示数值保留 3 位小数,同一面板只用弧度,角度与弧度不得混排。
- T 的显示值与 2π/ω 的复算容差 0.01;最大值读数与 A 的容差 0.01。

## 禁止生成
- 把周期公式写成 T = 2πω 或 T = ω/2π(应为 T = 2π/ω)。
- 声称 φ 决定周期或 ω 决定左右平移(ω 管周期,φ 管平移)。
- 把初相说成 ωx + φ(初相是 φ,ωx + φ 是相位)。
- 在 A、ω 为 0 或负值时不提示退化、照常绘制正弦型曲线。
- 把最大值标注成 A + |φ| 之类的和(y = Asin(ωx + φ) 的最大值就是 A)。
