## 核心概念
- 垂径定理:垂直于弦的直径平分弦,并且平分弦所对的两条弧;用「过圆心」「垂直」两个条件换「平分弦」「平分弧」两个结论。
- 弦心距 d、半弦 a/2、半径 r 构成直角三角形:(a/2)² + d² = r²;弓形高 h = r − d。
- 圆周角定理:同弧所对的圆周角等于它所对圆心角的一半;推论:同弧或等弧所对的圆周角相等;直径(半圆)所对的圆周角是直角;90° 的圆周角所对的弦是直径。
- 圆心角与所对弧一一对应:弧等则弦等、弦心距等;圆内接四边形对角互补。

## 公式与结论
- 弦长 a = 2√(r² − d²),弦心距 d = √(r² − a²/4),已知任意两个量可求第三个。
- 圆周角与圆心角:∠ACB = ∠AOB ÷ 2(同弧);圆心角 120° → 圆周角 60°;圆心角 180°(直径)→ 圆周角 90°。
- 典型算例:r = 5、d = 3 → 弦长 a = 8(3-4-5 直角三角形:半弦 4 + 弦心距 3 + 半径 5)。
- 圆内接四边形对角互补:一组对角 70° 与 110°,和为 180°。
