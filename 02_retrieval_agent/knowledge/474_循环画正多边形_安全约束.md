## 输入边界
- 边数 n 取 3~36 的整数；边长 10~200（步/像素）。
- 每次转角由 360° ÷ n 自动计算得出，不提供手动改转角的入口。
- n < 3 或转角 ≤ 0 时报错提示，不进入绘制。

## 禁止生成
- 把每次转角写成内角 (n−2)×180° ÷ n（程序转的是外角 360° ÷ n）。
- 转角公式写成 360° ÷ (n−1)、180° ÷ n 等错误变体。
- 声称总转角随边数或边长变化（恒为 360°）。
- 循环次数与 n 不一致（如重复 n−1 次）却声称画出正 n 边形。
- 单步演示中一步循环连走两条边或跳过转角。
