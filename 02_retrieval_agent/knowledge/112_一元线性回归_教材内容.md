## 核心概念
- 散点图先看形态:点大致落在一条直线附近才适合一元线性回归;样本相关系数 r ∈ [−1, 1],r > 0 正相关、r < 0 负相关,|r| 越接近 1 线性相关性越强。
- 一元线性回归模型 Y = bx + a + e,e 为随机误差;系数 b、a 未知,用成对样本数据给出最小二乘估计。
- 最小二乘原理:选取使残差平方和 Σ(yᵢ − ŷᵢ)² 最小的 b̂、â 作为估计值,b̂ 与 â 有公式可直接计算。
- 回归直线 ŷ = b̂x + â 恒过样本中心点 (x̄, ȳ);b̂ 与 r 同号。

## 公式与结论
- b̂ = Σ(xᵢ−x̄)(yᵢ−ȳ) ÷ Σ(xᵢ−x̄)²,等价写法 b̂ = (Σxᵢyᵢ − n·x̄ȳ) ÷ (Σxᵢ² − n·x̄²)。
- â = ȳ − b̂x̄:先算 b̂ 再算 â,次序反了会错。
- r = Σ(xᵢ−x̄)(yᵢ−ȳ) ÷ √[Σ(xᵢ−x̄)² × Σ(yᵢ−ȳ)²],r 的分子与 b̂ 的分子相同,故 r 与 b̂ 同号。
- 残差 eᵢ = yᵢ − ŷᵢ = 观测值 − 预测值,残差有正有负,使残差平方和最小的直线才叫最小二乘拟合直线。
- 典型算例:数据 (1,1)、(2,3)、(3,4)、(4,6),x̄ = 2.5、ȳ = 3.5,b̂ = 8 ÷ 5 = 1.6,â = −0.5,r = 8 ÷ √65 ≈ 0.9923。
