## 可调参数
标准液浓度(0.0500/0.1000/0.2000 mol/L)、滴加速率与半滴开关、指示剂选择(酚酞/甲基橙)、突跃区间高亮开关、V-pH 数据表开关

## 可复算量
- 起点 pH = −lg 0.1000 = 1.00(容差 ±0.01)。
- 等当点 V=20.00 mL、pH=7.00(25℃,容差 ±0.05)。
- 突跃边界:V=19.98 mL → pH≈4.30、V=20.02 mL → pH≈9.70(容差 ±0.05),突跃跨度 ≈5.4(容差 ±0.1)。
- c(待测) = 0.1000×20.00÷20.00 = 0.1000 mol/L(容差 ±0.0005 mol/L)。
- 曲线单调性:pH 随加入 NaOH 体积单调不减,页面曲线不得出现回落(容差 0)。

## 常见错误
- 认为等当点时溶液一定呈碱性(强酸强碱等当点为中性 pH=7)。
- 把指示剂变色点与等当点混为一谈(终点与等当点允许存在微小滴定误差,应尽量重合)。
- 滴定全程快速滴加、不做半滴操作,曲线失去「缓—陡—缓」特征。
- 用石蕊做定量滴定指示剂。
- 读数俯视/仰视,或只记终读数不记初读数。
