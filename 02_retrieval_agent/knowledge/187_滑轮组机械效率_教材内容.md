## 核心概念
- 有用功 W有 = Gh 是提升重物必须做的功；额外功 W额 是克服动滑轮自重、绳重与摩擦做的功；总功 W总 = W有 + W额 = Fs。
- 定滑轮能改变力的方向不省力；动滑轮省一半力但费一倍距离；滑轮组兼得省力与改变方向。
- 竖直绕法中 s = nh，n 是直接承担重物的绳段数（数连着动滑轮的绳段）。
- 不计绳重与摩擦时 F = (G + G动)/n；动滑轮越重、摩擦越大，机械效率越低。
- 机械效率 η 永远小于 1、无单位；同一滑轮组提升更重的物体时 η 升高。

## 公式与结论
- η = W有/W总 = Gh/(Fs) = G/(nF)，常用百分数表示。
- 例：G = 2 N、h = 0.1 m、n = 3、F = 0.8 N 时 η ≈ 83.3%，额外功 = 0.24 − 0.2 = 0.04 J。
- 由上例反推动滑轮自重（不计绳重摩擦）：G动 = nF − G = 2.4 − 2 = 0.4 N。
- 提高 η 的途径：减小动滑轮自重、加润滑油减小摩擦、增大提升物重；η 与提升高度无关。
