## 可调参数
类型切换(等差/等比)、a₁(−10~10,非零)、d(−10~10)或 q(−5~5,跳过 0)、n(1~50)、倒序相加/错位相减演示开关

## 可复算量
- 等差:Sₙ 两式互等(容差 0.01);散点逐点满足 aₙ = a₁ + (n − 1)d(容差 0.01)。
- 等比:Sₙ 封闭式与逐项累加一致(容差 0.01);散点逐点满足 aₙ = a₁qⁿ⁻¹(容差 0.01)。
- aₙ = Sₙ − Sₙ₋₁(n ≥ 2)与 a₁ = S₁(容差 0.01)。
- q = 1 时页面走 Sₙ = na₁ 分支,与逐项累加一致(容差 0.01)。

## 常见错误
- 等比求和忘记先判 q = 1。
- 等差展开式 d 的系数用成 n(n + 1) ÷ 2。
- 认为 aₙ = Sₙ ÷ n。
- q < 0 时丢负号(各项正负交替,Sₙ 按公式带符号)。
- 把数列散点用平滑曲线连线(数列是离散点,不能连线)。
