## 核心概念
- 标准方程 x²/a² + y²/b² = 1（焦点在 x 轴，a > b > 0）；焦点在 y 轴时两分母位置互换。
- c² = a² − b²：c 是半焦距，2a 是长轴长，2b 是短轴长。
- 离心率 e = c/a，0 < e < 1：e → 0 椭圆趋近圆，e → 1 椭圆越扁。
- 椭圆定义：平面内与两定点距离之和等于定值 2a（2a > 2c）的点的轨迹。
- a、b、c 满足 b² = a² − c²，是直角三角形关系，不是 a² + b² = c²。

## 公式与结论
- e = c/a = √(1 − b²/a²)。
- 顶点 (±a, 0)、(0, ±b)；焦点 (±c, 0)。
- 由 e 与 c 可推 a = c ÷ e、b = a√(1 − e²)。
- 典型算例：a = 5、c = 3 → b = 4、e = 0.6（3-4-5 直角三角形）。
