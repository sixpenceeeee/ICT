## 课标定位
属于初中「函数」主题（《义务教育数学课程标准（2022年版）》第四学段 数与代数，内容要求条目原名「反比例函数」）。学生在一次函数、二次函数之后第一次研究「乘积为定值」的两个变量，也是初中唯一图象为双曲线、与坐标轴不相交的函数。

## 内容与学业要求
- 结合具体情境体会反比例函数的意义，能根据已知条件确定反比例函数的表达式。（内容要求①）
- 能画反比例函数的图象，根据图象和表达式 y = k/x（k ≠ 0）探索并理解 k > 0 和 k < 0 时图象的变化情况。（内容要求②）
- 会用描点法画出反比例函数的图象；知道当 k > 0 和 k < 0 时反比例函数 y = k/x（k ≠ 0）图象的整体特征。（学业要求）
- 能用反比例函数解决简单的实际问题。（内容要求③）
