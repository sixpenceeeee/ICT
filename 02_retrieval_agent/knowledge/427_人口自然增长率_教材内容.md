## 核心概念
- 出生率指一年内出生婴儿数占总人口数的比率，死亡率指一年内死亡人数占总人口数的比率，都用千分率（‰）表示。
- 人口自然增长率 = 人口出生率 − 人口死亡率，反映人口自然增长的速度；大于 0 人口增加、等于 0 不增不减、小于 0 人口负增长。
- 自然增长率只反映出生、死亡决定的「自然增长」，不含迁移带来的机械增长。
- 人口基数越大，同一自然增长率下的年增长人口越多——这就是「基数大、增长多」。

## 公式与结论
- 人口自然增长率 = 出生率 − 死亡率（‰）。
- 年自然增长人口 ≈ 总人口 × 自然增长率 ÷ 1000。
- 读图口径：出生率、死亡率、自然增长率三条曲线同轴对比，上两条曲线的差就是第三条。
- 中国人口节按「数量变化—分布—政策」展开，三率曲线是把「变化」说清楚的数据支撑。
