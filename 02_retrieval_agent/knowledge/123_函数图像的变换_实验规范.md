## 演示构成
- 同坐标系叠加对比:原图象用实线、变换后图象用虚线并着色区分,两图同时可见。
- 参数面板:a(−3~3,跳过 0)、h(−5~5)、k(−5~5)滑块,拖动时变换图象实时重绘。
- 关键点联动:原图象关键点(如抛物线顶点与整数点)在变换图象上同步标记,用箭头线显示 (x₀, y₀) → (x₀ + h, a·y₀ + k) 的移动方向。
- 分步模式:可切换「只平移」「只伸缩」「先平移后伸缩」「先伸缩后平移」,每一步同步显示图象与当前解析式。

## 操作要点
- 关键点坐标必须按 (x₀ + h, a·y₀ + k) 独立复算并在面板显示,与曲线读数一致,审查器按该映射式对拍。
- y = f(2x − h) 这类 x 带系数的情形,页面必须按提系数后的平移量标注(如 f(2x − 1) 标注右移 ½),不得按字面 −1 标注右移 1。
- a = 0 时 y = af(x − h) + k 退化为常函数 y = k,须判定并提示,不得按「伸缩」绘制。
- 叠加对比时原图象保持不动,变换图象随参数移动;两图重叠时用线型与颜色双重区分,不能只改颜色。
- 翻折类变换(a < 0 或 y = f(−x))要给出翻折轴标注,防止把两种翻折混为一谈。
