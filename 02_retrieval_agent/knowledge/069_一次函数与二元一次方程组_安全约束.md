## 数值边界
- k 取 −5~5 且 k ≠ 0(k = 0 时 y = b 不是一次函数,判非法并提示);b 取 −10~10。
- |k1−k2| < 0.05 按平行处理并提示;交点超出视口(如 |x*| > 50)时标注「视口外」并给出数值。
- 坐标显示保留 2 位小数;回代相对误差的分母取 max(1, |右式|),避免 y* 接近 0 时误差虚大。

## 禁止生成
- k1 = k2、b1 ≠ b2(平行)时仍给出交点坐标,或把重合情形说成「无解」。
- 把方程组的解说成「就是交点的横坐标」(漏掉纵坐标)。
- 把 y = 3(k = 0 的情形)当作一次函数 y = kx + b 演示,或 k = 0 不拦截。
- 把图象读出的近似解直接当成精确解,不与消元法结果对照标注。
- 交点公式符号错,如把 x* = (b2−b1)/(k1−k2) 写成 (b1−b2)/(k1−k2) 而分母不随之变号。
