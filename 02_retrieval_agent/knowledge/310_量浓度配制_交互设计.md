## 可调参数
目标浓度(0.1000~1.000 mol/L 演示值)、容量瓶规格选择(100/250/500 mL)、溶质选择(NaCl/Na₂CO₃)、步骤推进(检漏→计算→称量→溶解冷却→转移洗涤→定容→摇匀)、错误操作对照开关(俯视/仰视、未洗涤、容量瓶内溶解)

## 可复算量
- c = n/V:0.1 mol 配成 500 mL → 0.2 mol/L(容差 ±0.001 mol/L)。
- m = c×V×M:250 mL、0.1000 mol/L Na₂CO₃ → 2.65 g(容差 ±0.01 g)。
- 误差方向判断与页面判定一致:俯视定容→偏高、仰视→偏低、未洗涤→偏低、瓶内原有少量水→无影响。
- 所选容量瓶规格与所配体积一一对应(选 250 mL 瓶不得出现 500 mL 体积)。
- 步骤顺序判定:检漏在转移之前、定容在摇匀之前,乱序判错(容差 0)。

## 常见错误
- 把 0.1 mol 溶质加进 500 mL 水当作 0.2 mol/L 溶液(溶液体积不等于水的体积)。
- 在容量瓶中直接溶解固体或加热。
- 转移不用玻璃棒引流、定容不用胶头滴管。
- 俯视与仰视的误差方向记反(俯视加水偏少、浓度偏高)。
- 忘记检漏或用容量瓶长期存放溶液。
