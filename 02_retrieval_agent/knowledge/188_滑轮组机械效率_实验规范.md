## 器材与步骤
- 器材：刻度尺、弹簧测力计、钩码、定滑轮与动滑轮（组成滑轮组）、铁架台、细绳。
- 步骤一：用弹簧测力计测出钩码重 G（或由钩码规格直接读取）。
- 步骤二：按绕绳方式装配滑轮组，记下钩码与绳端的初始位置。
- 步骤三：竖直向上匀速缓慢拉动绳端，在运动中同时读出拉力 F，并用刻度尺测钩码上升高度 h 与绳端移动距离 s。
- 步骤四：改变钩码个数、改换绕绳段数（n = 2 / 3）重复实验，比较 η 的变化。
- 步骤五：计算 η = Gh/(Fs)，分析额外功来源并整理器材。

## 操作要点
- 必须「竖直、匀速、缓慢」拉动且在运动中读数：静止读数漏掉摩擦做功，加速拉动读数偏大。
- h 与 s 必须对应同一段过程（同一起点、同一终点），页面要同步显示两个读数。
- n 的判断标准是「直接连着动滑轮的绳段数」，绕绳方式改变时 s 与 F 同步变化。
- 每组数据都要现场复算 η，并检查 0 < η < 1；η 不小于 1 说明测量或录入有错。
- 同一装置提升更重钩码时 η 升高，要用同一套滑轮组对比，不能换装置后再比较。
