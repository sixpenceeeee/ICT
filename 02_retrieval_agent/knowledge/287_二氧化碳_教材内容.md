## 核心概念
- 实验室用石灰石或大理石（主要成分碳酸钙）与稀盐酸反应制取二氧化碳，属于固液不加热型反应。
- 不用稀硫酸：生成的硫酸钙微溶于水，覆盖在大理石表面，阻止反应继续进行；不用浓盐酸：浓盐酸易挥发，挥发出的氯化氢气体混入二氧化碳使气体不纯；不用碳酸钠粉末：反应速率过快，不便于收集。
- 收集方法：二氧化碳能溶于水并与水反应，不用排水法；密度比空气大，用向上排空气法，导管口要伸到集气瓶底部。
- 验满与检验是两件事：验满看瓶口燃着的木条是否熄灭；检验看澄清石灰水是否变浑浊。
- 性质证据：倾倒二氧化碳使阶梯蜡烛自下而上依次熄灭（密度比空气大、不燃烧也不支持燃烧）；二氧化碳通入紫色石蕊溶液变红（与水反应生成碳酸）。

## 公式与结论
- CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑，两边原子守恒（Ca 1→1、C 1→1、H 2→2、O 3→3、Cl 2→2）。
- CO₂ + Ca(OH)₂ → CaCO₃↓ + H₂O，生成的白色沉淀碳酸钙是「石灰水变浑浊」的原因。
- CO₂ + H₂O → H₂CO₃，碳酸使紫色石蕊溶液变红；碳酸不稳定，受热易分解。
- CO₂ 相对分子质量 = 12 + 16×2 = 44，大于空气平均相对分子质量 29，这是向上排空气法的依据。
