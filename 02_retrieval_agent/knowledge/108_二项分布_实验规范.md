## 演示构成
- 分布柱状图:横轴 k = 0…n,柱高为 P(X = k),柱顶标注概率值(4 位小数);柱高按概率等比例,纵轴从 0 开始。
- 期望标注:在 E(X) = np 位置画竖直虚线并标注「E = np」数值;E ± σ 区间可叠加阴影。
- n、p 滑块拖动时全图重绘,面板显示 ΣP(k)、E、D、σ 四行实时读数。
- 试验模拟模式(可选):模拟 n 次试验成功次数的频次直方图与理论概率柱叠加对比。

## 操作要点
- 分布列必须列全 k = 0…n 且 ΣP(k) = 1(容差 0.001)——这是考试评分第一检查点,缺列或概率和不为 1 即判错。
- E、D 必须由公式独立重算对拍,不得手工写死;D 另用 Σ(k − np)²P(k) 复算(容差 0.01)。
- 独立重复是前提:页面不得出现「试验不独立仍用二项分布」的示例文案(对应考点「理解 n 次独立重复试验的模型及二项分布」)。
- p 接近 0 或 1 时图形严重偏斜,须提示「分布不对称」;概率为 0 的 k 值柱子保留空柱,不得省略横轴刻度。
