## 核心概念
- 状态参量：压强 p、体积 V、温度 T；系统处于平衡态时三个参量有确定值。
- 热力学温度 T = t + 273.15 K（粗算 273）：代入比例式计算必须用 K，不能用摄氏度。
- 玻意耳定律（等温）：p₁V₁ = p₂V₂；p-V 图上等温线是双曲线的一支，离原点越远温度越高。
- 查理定律（等容）：p₁/T₁ = p₂/T₂，p-T 图延长线过 −273 °C；盖—吕萨克定律（等压）：V₁/T₁ = V₂/T₂。
- 理想气体：宏观上任何压强、温度下都严格遵守三条实验定律；微观上忽略分子本身大小与分子间作用力（碰撞外）。
- 三条定律前提都是「一定质量」：漏气或充气时不再成立；pV/T = 常量 C 由气体质量与种类决定。

## 公式与结论
- pV/T = 常量（一定质量理想气体）；p₁V₁/T₁ = p₂V₂/T₂。
- 算例：p₁ = 1.0×10⁵ Pa、V₁ = 2.0 L、T₁ = 300 K → pV/T = 666.7 Pa·L/K；等温 V₂ = 1.0 L → p₂ = 2.0×10⁵ Pa。
- 等压 T₂ = 450 K → V₂ = 3.0 L（V ∝ T）；等容 T₂ = 450 K → p₂ = 1.5×10⁵ Pa（p ∝ T）。
- 统计观点：压强是大量分子频繁碰撞器壁的平均效果；温度是分子平均动能的标志。
