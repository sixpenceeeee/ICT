来源: 平台内容安全边界（虚拟实验，不指导真实操作）

## 数值边界
- a ∈ (0, 1) ∪ (1, 10) 且强制跳过 1;a = 1 或 a ≤ 0 判定为非法输入并提示(a = 1 时 y = aˣ 恒为 1,y = log₁x 无定义)。
- 指数函数 x ∈ [−5, 5];对数函数真数必须大于 0,x = 0 及负数不得取点,取点时提示「真数必须大于 0」。
- y 轴显示范围钳制 [0.01, 100];数值显示保留 3 位小数;logₐ(aˣ) 与 x 的复算容差 0.01。

## 禁止生成
- 在 a = 1 或 a ≤ 0 时绘制「指数/对数函数」曲线。
- 把恒过点写反:指数函数过 (0, 1),对数函数过 (1, 0),不得互换。
- 声称两图象关于 y = −x 或坐标轴对称(同底指数与对数图象关于 y = x 对称)。
- 把 logₐ(aˣ) 写成 aˣ 或把 a^(logₐx) 写成 logₐx(两者都应还原为 x)。
- 对数真数取 0 或负值仍计算数值(真数必须大于 0)。
