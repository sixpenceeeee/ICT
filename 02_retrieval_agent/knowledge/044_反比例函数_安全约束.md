## 数值边界
- k 取值范围 -10 到 10 且 k ≠ 0；k = 0 必须判定为非法输入并提示「k = 0 时不是反比例函数」。
- 采样点 |x| ≥ 0.1，否则 y 值发散；|x| < 0.1 的点不参与绘制，显示数值保留 2 位小数。
- 矩形面积显示值必须等于 |k|（容差 0.5%），k < 0 时不得把面积显示成带负号的 k 本身。

## 禁止生成
- 把 k = 0 或 x = 0 的点画进图象（双曲线与坐标轴无交点、不经过原点）。
- 跨支表述增减性，如「k > 0 时 y 随 x 增大而减小」不限定「在每一支上」。
- 把 k > 0 的图象画到第二、四象限（象限与 k 符号弄反），或由象限反推 k 符号时弄反。
- 用一次函数的办法求 k，如写成 k = y₀ ÷ x₀（那是正比例系数，反比例应 k = x₀·y₀）。
