## 核心概念
- 真彩色图像每个像素由 R、G、B 三个通道表示，每通道取值 0~255；灰度图每个像素只有一个亮度值。
- 灰度化按固定权重把三个通道压成一个值：人眼对绿色最敏感、蓝色最不敏感，故 G 权重 0.587 最大、B 权重 0.114 最小——是加权平均，不是简单平均。
- 三个权重之和为 1，保证纯白 (255,255,255) → 255、纯黑 (0,0,0) → 0，结果不会越出 0~255。
- 常见取整方式：四舍五入（round）与截断（int）；同一像素两种方式可差 1，报告结果须注明所用规则。

## 公式与结论
- Gray = 0.299R + 0.587G + 0.114B（ITU-R BT.601 亮度公式），0 ≤ Gray ≤ 255。
- 权重和 = 1.000：对任意 R=G=B=v 的像素，Gray = v。
- 纯色检验值（四舍五入口径）：纯红 (255,0,0) → 76，纯绿 (0,255,0) → 150，纯蓝 (0,0,255) → 29。
- 未压缩时每像素由 3 字节降为 1 字节，数据量约为原来的 1/3；灰度化有信息丢失，不可逆。
