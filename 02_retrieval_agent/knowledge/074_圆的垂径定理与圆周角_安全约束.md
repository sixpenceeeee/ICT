## 数值边界
- r ∈ [2, 10],d ∈ [0, r) 强制生效;d ≥ r 时弦不存在(点在圆上或圆外),必须判定为非法输入并提示。
- 圆心角 θ ∈ (0°, 360°),圆周角按所对弧取值落在 0°~180°;角度显示保留 1 位小数,长度保留 2 位小数。
- (a/2)² + d² 与 r² 的复算容差 1%;显示数值不使用科学计数法。

## 禁止生成
- 把圆周角定理写成「圆心角等于圆周角的一半」(关系反了,应为圆周角是圆心角的一半)。
- 把「过弦中点的线段」直接说成直径而不验证垂直与过圆心,或把垂径定理用于只有「平分」没有「垂直」的线段。
- 动点 C 在优弧一侧时仍按劣弧所对圆心角报数,造成圆周角读数与 ∠AOB/2 矛盾(应加 180° − ∠AOB/2 或切换所对弧)。
- 用 (a/2)² + d² = r² 时把 d 当成半弦(混淆弦心距与半弦,导致弦长漏乘 2)。
