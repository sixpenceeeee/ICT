## 数值边界
- 向量分量取值 −10~10;|a|、|b| 均须 > 0,零向量必须拦截(无夹角、无投影)。
- cosθ 保留 3 位小数,θ 保留 1 位小数,a·b 保留 2 位小数。
- a·b 的定义式与坐标式互差 ≤ 0.01,超出即判定非法状态,停止渲染。

## 禁止生成
- 把数量积写成 |a||b|sinθ,或把结果画成向量(数量积结果是数量)。
- 把两向量夹角取成 0°~90°(夹角范围是 [0°, 180°],cosθ 可为负)。
- cosθ < 0 时仍把投影向量画成与 a 同向。
- 由 a·b = 0 断言 a、b 中有零向量(非零向量时 a·b = 0 是垂直)。
- 坐标式写成 x₁y₁ + x₂y₂(坐标抄错位)。
