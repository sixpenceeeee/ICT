## 核心概念
- 形如 y = k/x（k 为常数，k ≠ 0）的函数是反比例函数，等价写法 xy = k、y = kx⁻¹。
- 图象是双曲线，分两支，以 x 轴、y 轴为渐近线；与两坐标轴不相交，不经过原点。
- k > 0 时两支分别在第一、三象限，每一支上 y 随 x 增大而减小；k < 0 时两支在第二、四象限，每一支上 y 随 x 增大而增大。增减性必须限定「在每一支上」，跨两支比较无意义。
- 双曲线既是中心对称图形（对称中心为原点），又是轴对称图形（对称轴为直线 y = x 与 y = -x）。

## 公式与结论
- 待定系数法由一点求 k：图象过点 (x₀, y₀) 时 k = x₀·y₀，横纵坐标相乘，一点定 k。
- k 的几何意义：图象上任一点向两坐标轴作垂线，垂线段与坐标轴围成的矩形面积恒等于 |k|。
- 图象上的点成对关于原点对称：(a, b) 在图象上，则 (-a, -b) 也在图象上。
- 典型列表点（k = 6）：x = 1→y = 6，x = 2→y = 3，x = 3→y = 2，x = 6→y = 1，描点连线得第一象限一支。
