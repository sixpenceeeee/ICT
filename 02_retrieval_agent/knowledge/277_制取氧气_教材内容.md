## 核心概念
- 两条制取路线：加热高锰酸钾（固固加热型）；过氧化氢溶液加二氧化锰催化（固液不加热型）。
- 二氧化锰是催化剂：改变反应速率，反应前后质量与化学性质不变。
- 收集方法：氧气不易溶于水 → 排水法；密度比空气大 → 向上排空气法。
- 验满：向上排空气法用带火星木条平放瓶口；排水法看到瓶口有大气泡冒出。
- 加热高锰酸钾时试管口放一团棉花，防止粉末随气流进入导管。

## 公式与结论
- 2KMnO₄ --Δ--> K₂MnO₄ + MnO₂ + O₂↑；2H₂O₂ --MnO₂--> 2H₂O + O₂↑。
- 操作顺序（加热路线）：检查气密性 → 装药固定 → 加热 → 收集 → 撤导管 → 熄灯。
- 试管口略向下倾斜，防止冷凝水回流到热的试管底部使其炸裂。
- 催化剂「一变两不变」：改变化学反应速率，自身质量与化学性质不变。
