## 演示构成
- 坐标系中绘制椭圆，标注长轴端点、短轴端点与两焦点。
- a、c（或 a、e）滑块拖动时曲线实时重绘，数值面板显示 b 与 e。
- 显示「到两焦点距离之和 = 2a」的验证：任取曲线上一点，画两条焦半径并读数求和。
- 提供离心率对比：同屏绘制 e = 0.2 / 0.6 / 0.9 三个椭圆，直观对比扁平程度。

## 操作要点
- 参数约束 a > c 必须强制生效：a ≤ c 时提示「不构成椭圆」并停止绘制。
- 曲线上任取点 P，|PF₁| + |PF₂| 恒等于 2a，读数与理论值误差应在 1% 内。
- 焦点在 x 轴 / y 轴切换时，方程与标注要同步更换，不能只换图。
- e 与 a、c 联动时数值必须一致，不能出现 e 与 c/a 相互矛盾的状态。
