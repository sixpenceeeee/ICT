## 安全边界
- 演示拉力上限 50 N、小车质量上限 10 kg、加速度上限 30 m/s²,超出范围提示「超出演示量程」。
- 演示用电磁打点计时器,标注 4~6 V 低压交流电源;不出现 220 V 电火花计时器的真实接线内容。
- 垫高木板平衡摩擦力时垫块高度有上限提示,防止小车滑出桌面;导轨与滑块固定操作提示由教师完成。
- 页面显示的力、质量、加速度数值必须满足 a = F/m 自洽,出现矛盾状态(如 F = 0 而 a ≠ 0)视为错误状态。

## 禁止生成
- 生成「未平衡摩擦力就得到 a = F/m 结论」的操作步骤(F 必须是合外力)。
- 槽码质量不小于小车质量时,仍宣称绳的张力等于槽码重力。
- 输入质量为 0 或负值,或合外力为 0 而要求非零加速度。
- 把 a = F/m 写成 F = m/a 或 a = m/F,或把加速度与速度混为一谈。
