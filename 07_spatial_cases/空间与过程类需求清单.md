# 空间与过程类教学工具需求清单

> 触发点：需求方提出「立体几何中切割、重合」这类 HTML。
> 结论：这不是一个孤立案例，而是暴露了现有 115 条清单完全缺失的一整个交互维度——**空间**。

---

## 一、先说结论

现有清单 115 条里，**立体几何相关为 0 条**，全部案例都建立在「滑块 → 数值 → 曲线」这一范式上。
而「切割、重合」要求的是另一种东西：**在三维空间里对几何体做操作，答案是一个形状或位置关系，不是一个数**。

把这类需求拆开，`切割` 和 `重合` 只是两份，同族还有更多：

| 空间能力的六个考点 | 对应需求 | 本清单是否覆盖 |
|---|---|---|
| ① 截面想象 | **切割**（平面截多面体） | ✅ MA-H13 |
| ② 展开折叠 | **重合**（展开图折回、两体拼合） | ✅ MA-H14 / MA-J10+ |
| ③ 投影识图 | 三视图与直观图 | ✅ MA-H12 |
| ④ 旋转成体 | 面动成体、旋转体体积 | ✅ MA-H15 |
| ⑤ 位置关系 | 平行/垂直/异面、二面角、距离 | ✅ MA-H17 / MA-H16 |
| ⑥ 度量计算 | 切接球、体积、表面积 | ✅ MA-H18 / MA-H20 |

这六项就是高中立体几何的全部必修内容。你的需求落在第①和第②项，另外四项是同等量级的需求。

## 四、技术路线：切割到底要不要 3D 引擎

这是本清单里唯一会「做错方向」的地方，先说结论：**切割不需要 Three.js。**

| 方案 | 适用 | 文件体积 | 能做切割吗 |
|---|---|---|---|
| **C2** Canvas 2D + 手写投影 | 凸多面体、解析可算的几何。约 300 行，文件 < 80 KB | < 80 KB | ✅ 能，且结果可精确复算 |
| **CSS3D** CSS 3D transform | 只需整体旋转观察的简单多面体，零依赖、文件最小 | < 40 KB | ❌ 无深度缓冲，做不出真实截面 |
| **T3** 内联 Three.js | 需要曲面 / 材质 / 真实感，如分子、球体、地球。文件约 700 KB | 约 700 KB | ⚠️ 能切开，但体积/截面要自己另算 |

我写了 `prototype_section.py` 验证第一条：平面与正方体 12 条棱求交 → 按平面内极角排序得到截面多边形 → 沿法向切片积分得两部分体积。

实测结果：

| 平面 | 截面形状 | 两部分体积 | 校验 |
|---|---|---|---|
| z = 0.5 | 正方形，面积 1.000000 | 0.500000 / 0.500000 | 通过 |
| x+y+z = 1.5 | **正六边形**，面积 1.299038 | 0.500000 / 0.500000 | 通过 |
| x+y+z = 1.0 | 正三角形，面积 0.866025 | 0.166667 / 0.833333 | 通过 |
| x+y = 1.0 | 矩形，面积 1.414214（= √2） | 0.500000 / 0.500000 | 通过 |
| x+2y+3z = 2.5 | **五边形**，面积 1.169268 | 0.336806 / 0.663194 | 通过 |

顶点共面误差 0，体积守恒到 1e-9。**结论：截面形状、边数、两部分体积都是可解析求出的确定值。**

反过来看，用 3D 引擎的裁剪平面做「切割」：视觉上确实切开了，但截面是几边形、两部分体积比是多少，
引擎不会告诉你——而这恰恰是这道题要考的东西。**为了视觉效果引入引擎，反而让审查失效。**

技术选型的判断规则：

- 凸多面体 + 截面/展开/投影 → **Canvas 2D 手写投影**（29 条）
- 分子、球体、地球、需要材质光照 → **内联 Three.js**（9 条）
- **CSS 3D：本清单一条都没用**。它只能整体旋转，做不了截面；而凡是它能做的（比如 多面体与旋转体的结构 的多面体观察），Canvas 2D 也能做，并且能顺带导出顶点坐标供审查。**能复用一套渲染就不要再引入第二套。**

## 五、审查怎么升级（这是真正的改造成本）

现有审查器只会「抓页面文字 → 正则有公式 → 复算」。3D 页面没有那句文字，会全线失效。

**解法：要求页面同时暴露一份可计算的几何表征。**

```js
window.__GEO__ = {
  vertices: [[0,0,0], [1,0,0], ...],   // 立体几何：顶点
  faces:    [[0,1,2,3], ...],          //       面索引
  section:  [[0.5,0,1], ...],          //       当前截面顶点
  volume:   [0.3368, 0.6632],          //       两部分体积
};
```

审查器读它，验四件事：

| 检查项 | 判据 | 抓什么错 |
|---|---|---|
| 拓扑有效 | V − E + F = 2 | 面接错、漏面 |
| 截面共面 | 所有 section 点到平面距离 < 1e-6 | 截面是「折的」 |
| 边数正确 | 截面边数 = 与之相交的面数 | 少算/多算一条边 |
| 体积守恒 | V₁ + V₂ = a³（误差 < 1e-6） | 切割后总体积变了 |

这和之前要求「公式必须显示代入式」是同一个原则：
**凡是视觉上呈现的东西，都要同时给出一份机器能复算的表征。**
这条原则现在可以上升到整个系统的设计准则，答辩时是加分项。

注意一个反向约束：**相机旋转角度一律不进入判据**。旋转是体验，不是考点。
审查时应固定相机或在数学层校验，绝不能用「截图比对」——同一个几何体换个角度就完全不同，
像素级比对只会制造假阳性。

## 八、救回了两条原清单判「不做」的案例

| 原 ID | 原判断理由 | 现在的机会 |
|---|---|---|
| `PH-H08` 带电粒子在磁场中 | 平面画不出螺旋轨迹 | `PH-H09`：3D 轨迹 + **周期与速度无关**这个不变量，判据反而变强了 |
| `CH-H09` 晶体结构与配位数 | 只能验标注齐全，验不了对错 | `CH-H11`：配位数、晶胞粒子数、密度三者都可复算 |

这说明「不做」的判断要定期复检：**技术路线变了，可行性就会变。**

仍然不做的：`GE-H02` 热力环流（定性，无标量）、`BI-J07` 心脏结构标注（位置无法客观判定）。
这两条换 3D 也救不回来，判断标准是「有没有可复算的量」，不是「能不能画得更好看」。
