⑥ 教学说明（原理 / 易错点 / 探究问题）

原理

物体温度变化吸收或放出的热量 Q = cmΔt。质量越大、比热容越大，同样热量下温升越小。

易错点

Δt 是温度变化量而不是末温；放热时 Δt 取负，热量取绝对值。

探究问题

同样的热量，质量加倍后温升变成多少？再换一种比热容更大的物质比较。
